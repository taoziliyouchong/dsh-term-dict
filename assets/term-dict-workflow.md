# 术语字典（两级）

**用途：存放我和你「约定俗成的称谓」以及它们的「默认指代」**——某个词在我们之间指什么、单独出现时默认先指哪个、边界在哪、算不算数。不收行为规则（那是模式与规则文件的事），也不收一次性参数（那是工作区文件的事）。

**两层全部集中在一个根目录 `$DSH_HOME\dict\` 下**（通用 `general.md`、任务 `domains\<任务slug>.md`）——要翻全部字典只开这一处。

| 层 | 文件 | 收什么 |
|---|---|---|
| 通用 | `$DSH_HOME\dict\general.md` | 跨任务类型都成立的称谓 |
| 任务 | `$DSH_HOME\dict\domains\<任务slug>.md` | 只在本类任务里成立的称谓，含只对某个工作区成立的默认落点 |

## 任务层＝一类任务，任务类型由它自己声明

任务字典的表头写一行：

```
> 任务类型：<任务类型中文名>
```

宿主的 `/api/list` 与面板就显示这个中文名（没写时退回 slug）。**这份说明取自任务文件自身，不读任何外部。**

**不留「未归类」**：要登记一个工作区的称谓，先看它属于哪一类任务——没有现成的，就新开一个任务：建 `dict\domains\<slug>.md`、表头写中文任务类型名。

**slug 只是一类任务的标识**：目录名、文件名用同一个 slug 串起来即可，改名就整体改名；工具与面板都按文件实际名字读，不另存索引。

**一个任务对多个工作区是常事**：同一类任务下可以同时挂几个工作区。默认落点被它们共用、又各指不同文件时，词条里写清是哪个工作区（备注写一句「本项目＝哪个工作区」），别让一个词条同时指两处。

## 收录判据

三类都收：① 我和你约定俗成、不记下次还得重对口径的称谓；② **默认指代**——一个通用词在我们语境里单独出现时，默认优先指的那件事；③ **默认落点**——一个一般词在某个任务里默认指哪份**文件**／哪条**命令**／哪件事（「报告」指哪份、「总表」指哪个、「扫一下」是跑哪条）。

三类都不沾的不收。另外不收：文件名本身、书名、工程名、编号这类专名；工作区文件地图里已经写清、一眼可知的词。

**与工作区文件地图冲突时以字典为准**：文件地图答「有哪些文件」，字典答「你嘴里的词指哪份」；两边都写了、说法不一致，按字典读。

**只记你在用的叫法**：词条名与定义来自你——你说过的词、你明确认过的名字；我造的词只要你在用，也收。别把你的意思改写成我的措辞再写进来（那等于把我造的概念冒充成我们的约定）。

## 三类词条（类型不写进文件，由主字段推断）

| 类型 | 判据 | 最小字段 | 例 |
|---|---|---|---|
| 称谓型 | 答「这个东西我们叫什么」 | `定义` ＋`状态`；`默认指代／边界／别称／备注`（备注指向技能、撞名规则也写这里）按需 | 某个概念、某套方法、某个代号 |
| 落点型 | 答「你说这个词时默认指哪个」 | `默认指代` ＋`状态`；`边界／别称` 按需 | 某份报告、某个总表、某条命令 |
| 留档型 | 已废，只答「为什么不用」 | `定义`（一句为什么）＋`状态：已废` | 旧叫法、合并掉的别名 |

判据在代码里只此一处（面板与体检同源）：状态＝已废 → 留档型；有 `默认指代` 且无 `定义` → 落点型；其余 → 称谓型。**落点型不要求写「定义」**——「你说『报告』时的指代对象」这类话是套话，删掉不丢信息，有真边界才写边界。面板按类型只显示本类型用得到的字段，保存时把本类型用不到的字段剔掉（切类型不会动已写的字，剔之前会先提示剔哪些）。

## 词条格式

```
## 词条名（别名：另一叫法、再一个叫法）
- 定义：一句话（它指什么）
- 默认指代：单独出现、没有别的限定时，默认优先指的那件事（也可以是一份文件的路径、一条命令、一个动作）
- 边界：不是什么；给得出例子就写成「例：…」（原来单列的「反例」并进这一行）
- 状态：已确认 / 部分确认 / 待观察 / 已废
- 备注：可选；撞名认哪条也写在这里（「排他性＝…」，原来单列的「排他性」并进这一行）
```

字段只剩五行；**别名不单列字段，直接写进标题的括号里**（`## 词典（别名：字典、术语字典）`）——查别名照样命中，格式里少一个字段。

除「定义」外都是可选；有默认指代就写那一行，没有就留空。**字典里只写「这个称谓指什么」，方法本身写在技能里**——要指某套方法就写一句「别称」或备注指向技能名，别在字典里再抄一份要点（抄两处，将来改一处忘一处）。

### 默认指代：一个词的默认落点

同一个词在我们这儿可能有多义（比如「扫描」既能指扫某个业务口径、也能指扫目录），但多数时候你单独说它，心里只有一件事。**「默认指代」就是那一件事**：这个词单独出现、没有别的限定时，我按它读；一旦有别的限定了（「带限定的扫描」），就不按默认指代读。有默认指代才写这一行，没有就留空。

落点三类，都写在这一行里：

| 落点 | 写法 | 例 |
|---|---|---|
| 一件事／一个动作 | 一句话说清做的是哪件事 | `默认指代：跑当天那件事，产出到 归档\<日期>\` |
| 一份文件／目录 | 写绝对路径，或相对该工作区的路径 | `默认指代：产出\<文件名>\报告.md` |
| 一条命令／入口 | 原样写命令或入口名 | `默认指代：/命令名` |

一条一句话、不带案例与日期；路径变了就改这一行——字典是查词时的第一入口，过期比没有更坏。

**默认会变时（暂时性的默认指代）**：默认指代那一行以「目前＝」开头，状态写 `部分确认`，备注写一句「换 X 时改这一行」。看到「目前＝」就当它是活的：别当铁板钉钉的约定用，也别因为「词典写过」而拒绝变——你要改，我改这一行就完事。

### 别称：一词多叫的入口

「术语字典／字典／dict」这类同一物的多个叫法写进「别称」，`dict action=lookup` 用别称也能查到本条（命中时会标「命中别称」）。**不写别称＝下次换个叫法查空**，所以约定俗称的简写、英文名、口语叫法都往里放。

### 反例：比抽象边界更好用

「边界」是抽象一句话，「反例」给一个具体例子——出现这个，就不算这个称谓。判断快得多：说「这个不算约定，算规则」，就是一条反例。

### 排他性：撞名认哪条

同一个词在两层出现时，默认认 **任务 > 通用**（越具体越优先）。要反过来、或与别的词条撞名时要指定，就写「排他性」字段。

体检 `dict action=lint` 按这个规则报：跨层同名**定义不同**＝正常，另出「审计（非问题）」行告诉你认哪条；同名**定义相同**＝任务层白抄一份，报「可删重」；定义不同又没写排他性＝报一条；别称跟别的词条名或别称撞车＝报一条。

## 三个入口

| 入口 | 用途 |
|---|---|
| 设置 →「术语字典」（面板） | 人看人改：左栏树（通用／任务），右侧「词条」视图点一条改四个字段、「原文」视图批量整理 |
| 工具 `dict`（action=lookup／write／lint） | 我在会话里查、写、体检；未收录时给「疑似同一词」候选 |
| 自动激活（本插件，`activation.js`） | 用户消息、我的思考与输出里**第一次**出现词条名／别称时，把该条口径作为 runtime-context 注入；同一会话同一条只注入一次 |
| 直接开文件 | 批量整理、批量替换时最快 |

**自动激活的边界**：用户消息里的词在本次模型调用前生效；我的思考／输出里的词只能从下一步或下一轮生效（正在流式生成的那一段改不了）。只认精确命中（词条名／别称），不做形近联想——形近候选仍走 `lookup`。通用会话（没有模式或判不出模式）默认灌注；其余模式要设置里勾了「灌注的模式」才灌注，新建的模式默认不灌。任务层要绑了工作空间才默认生效，没绑默认不灌。状态记在 `$DSH_HOME\dict\.activation.json`。

## 什么时候用

- 涉及术语口径（「你说的 X 指什么」）→ 先 `dict action=lookup` 查（别称也查得到），别凭记忆答；查不到时看「疑似同一词」候选——形近的词，说不定就是同一个，先确认再按那条办。
- 自动激活已经把某条口径注入时，按注入的那条办；注入的词条与当前语境不符（同词不同义、有别的限定）时，按该条的「默认指代／边界」读，必要时问一句。
- 产出用的称谓之前扫一遍（三种情形：词有歧义／你换叫法说同一物／我临时造了个叫法）→ 立刻走「查→认→定→记」，查不到且有歧义就问一句、只是叫法不同就按已约定那条办；**记的时候只记你的叫法**。
- 扫的时候可以提意见：更省事的叫法、更准的指代、两词该合该分（也包括本机制自己的叫法）→ 当轮说一句「这词……，建议改叫……，你说行我就改」，**提议放正文、等你说行才改文件**。
- 定下新口径 → `dict action=write` 落条；任务层给 domain（`dict\domains\` 下那个文件的 slug），通用层直接写 layer=通用。
- 改完或定期 → `dict action=lint` 体检（空定义／缺状态／重名／别称冲突／跨层同名同义可删重／跨层同名异义缺排他性／**疑似同一个词：两条名字只差一个字，确认合并还是并进别称**）。

## 状态怎么用

- 已确认：双方拍板过。
- 部分确认：主料定了、细节待定（备注写清待定的是哪几项）。
- 待观察：只出现过一次，按线索挂着。
- 已废：本阶段确认不用（词条保留，写清为什么不用）。**已废≠这个词以后永不录用，也不代表不能改好复出**——它只是「这会儿不用」的记号：哪天要用、或把它改明白了，把状态改回来就行。别拿它当封条，也别拿它当挡箭牌拒绝再提。

## 落点与写入口

字典文件统一在 `$DSH_HOME\dict\`：通用 `general.md`、任务 `domains\<任务slug>.md`。任务层要新建就先建文件、表头写 `> 任务类型：中文名`，工具与面板随后自动识别。

```
dict  { "action": "lookup", "term": "某词" }
dict  { "action": "write", "term": "……", "definition": "……", "layer": "任务", "domain": "<任务slug>" }
```
