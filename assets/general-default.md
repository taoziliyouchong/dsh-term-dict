# 术语字典·通用层

> 收录判据：双方都在用、会出现口径分歧的称谓。格式：`## 词条名` 下面「- 定义／- 默认指代／- 边界／- 状态／- 备注（别名写进标题：`## 词条名（别名：另一叫法）`）」（除定义外可选）。

## 词条（别名：词目）
- 类型：称谓型
- 定义：术语字典里的一条记录，带定义／默认指代／边界／反例／别称／状态。
- 默认指代：单说「词条」指字典里的一条记录。
- 边界：不是回复里的列表项、编号条目，也不是待办事项。
- 反例：「待确认项」是待办，不是词条。
- 状态：已确认
- 备注：一条词条就是一条口径；改口径改字段，不另起一条。

## 词典（别名：字典、术语字典）
- 类型：称谓型
- 定义：存放「我们之间约定俗成的称谓」与它们默认指代的两级文件——通用层、任务层。
- 默认指代：单说「字典」指 $DSH_HOME\evolve\dict\ 下的通用层与任务层文件。
- 边界：不存行为规则、不存一次性参数与项目私有细节。
- 反例：把「不要用比喻」这类行为规则写进字典，就不算词典词条。
- 状态：已确认
- 备注：面板＝设置 → 术语字典；工具＝dict。
